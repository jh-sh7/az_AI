# 프론트엔드

React와 TypeScript로 구현된 프론트엔드 애플리케이션입니다.

## 설치

```bash
npm install
```

## 환경 변수 설정

`.env` 파일을 생성하고 다음 변수들을 설정하세요:

```
REACT_APP_API_URL=http://localhost:8000
REACT_APP_GOOGLE_CLIENT_ID=your-google-client-id
```

## 실행

```bash
npm start
```

브라우저에서 http://localhost:3000 으로 접속하세요.

## 빌드

```bash
npm run build
```
